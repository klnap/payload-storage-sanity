# Security policy

## Supported versions

Only the latest published version receives security fixes.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/klnap/payload-storage-sanity/security/advisories/new). Do not disclose vulnerabilities in public issues.

Reports concerning access control, webhook verification, asset handling, secret exposure, and release integrity are especially relevant.

Sanity CDN asset URLs are public. Payload access control does not make CDN assets private.
